# Recipe Planner

Recipe Planner — це застосунок для зберігання рецептів та формування списків покупок. Програма дозволяє додавати власні рецепти, переглядати інгредієнти, шукати страви, змінювати кількість порцій та зберігати улюблені рецепти.

## Предметна область

Застосунок призначений для роботи з кулінарними рецептами. Користувач може створювати рецепти, зберігати інгредієнти та етапи приготування, виконувати пошук і фільтрацію рецептів, а також формувати список продуктів для покупки.

## Основні можливості

* створення рецептів;
* редагування рецептів;
* видалення рецептів;
* збереження інгредієнтів та етапів приготування;
* пошук рецептів за назвою;
* фільтрація рецептів за категоріями;
* сортування рецептів;
* масштабування кількості інгредієнтів;
* формування списку покупок;
* робота з улюбленими рецептами;
* збереження налаштувань застосунку.

## Використані технології

* C#
* .NET 10
* JSON serialization (System.Text.Json)
* NUnit

Містить unit-тести для основної бізнес-логіки:

* RecipeServiceTests
* FakeRecipeRepository

## Збереження даних

Для усунення хардкоду шляхів та дотримки архітектурних вимог, збереження даних повністю перенесено в системну директорію користувача.

Робочі файли динамічно створюються та оновлюються за шляхом:

```text
%AppData%/RecipePlanner/
```

* `recipes.json` — база даних рецептів (підтримує збереження кирилиці в UTF-8 без Юникод-кодування завдяки JavaScriptEncoder.UnsafeRelaxedJsonEscaping).
* `settings.json` — конфігурація застосунку (стандартна кількість порцій та дефолтне сортування).

### Механізм сидування

У разі відсутності файлів у системній директорії `%AppData%` (наприклад, при першому запуску на новому комп'ютері), застосунок автоматично копіює базові заготовки з дефолтними рецептами (зокрема, "Карбонара") з папки збірки, розгортаючи готову до роботи інфраструктуру.

## Запуск програми

Проєкт містить попередньо скомпільовану автономну версію, яка не потребує встановлення .NET SDK або Visual Studio на комп'ютері.

Для швидкого запуску:

1. Перейдіть до папки `Start` у корені репозиторію.
2. Запустіть файл:

```text
RecipePlanner.exe
```

## Тестування

Unit-тести покривають логіку роботи сервісів та запускаються через Test Explorer у Visual Studio.

## Приклади даних

Вхідні базові шаблони файлів `recipes.json` та `settings.json` інтегровані безпосередньо в проєкт `RecipePlanner.ConsoleUI` із налаштуванням автоматичного копіювання `Copy if newer`, що забезпечує коректне постачання початкових тестових даних через GitHub.
